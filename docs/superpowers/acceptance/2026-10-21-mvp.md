# MVP acceptance results — 2026-10-22

## How this was run

The plan called for a live interactive Claude Code session. The controller ruled for headless runs
(`claude -p`) instead. The first headless run failed before reaching the model:

```
AFC_HOME=<temp> claude -p "hi" --output-format json --permission-mode acceptEdits
→ Failed to authenticate: OAuth session expired and could not be refreshed
```

So no model-driven step could be observed. Everything deterministic was run directly against the real
code: the SessionStart hook, the CLI, and the PreToolUse guard (fed the same JSON events Claude Code
sends). Anything that depends on the model's behaviour is marked **user to confirm**. All runs used a
temp `AFC_HOME` and a temp parent folder; the real `~/.A-FC` was not touched.
