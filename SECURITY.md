# Security policy

## Supported versions

Security fixes are provided for the [latest release](https://github.com/sky2464/AFC/releases/latest) on the default branch. Older tagged releases are not supported unless noted in a release announcement.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Report vulnerabilities privately through GitHub **private vulnerability reporting** for this repository:

1. Open [sky2464/AFC](https://github.com/sky2464/AFC).
2. Go to **Security** → **Report a vulnerability** (or use [GitHub's advisory form](https://github.com/sky2464/AFC/security/advisories/new) when enabled).

Include enough detail for us to reproduce the issue (affected version, steps, impact). We will acknowledge your report and work on a fix; coordinated disclosure is preferred.

If private reporting is unavailable, use the [Security tab](https://github.com/sky2464/AFC/security) contact options GitHub provides for this repository rather than posting details in issues or pull requests.
